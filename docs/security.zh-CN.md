# 安全与隐私

[文档目录](README.zh-CN.md) · [English](security.md)

自行部署让你控制存储与配置，但不意味着全部数据留在本地，也不意味着录音端到端加密。媒体桥可以处理和记录音频；启用的 AI、转录、报告服务可能向配置的外部供应商发送音频或文字；移动推送服务也会收到配置的载荷，其中可能包含主叫信息。

## 保护边界

- Control、媒体、TURN、Voice 和数据库仅获得必要凭据与文件权限。使用独立高熵密钥、受限权限、鉴权私有路由和严格 TLS。
- 数据库、管理基础设施和内部 worker API 不向公网开放。不要为了排障公开带凭据的调试接口。
- 保留真实的用户归属、网关 epoch、SIM 分配、命令 generation 检查。配对码短期有效，设备令牌与模组凭据副本则持续敏感，直至撤销或更换。
- 原生签名身份、关联域、Android 证书 origin 和推送 topic 必须与安装包匹配。不分发签名私钥、Apple 私钥、Firebase 服务账号、真实设备 token 或填好的本地配置。
- root Pixel 与模组 helper 都具有高权限，安装前审核实际二进制、模块权限、签名和支持的系统/固件。

## 数据生命周期

清点联系人、号码、短信正文、录音、转录、AI 人设、凭据、设备元数据、诊断、导出和备份，分别制定权限与保留策略。运维报告、真机证据和原始日志放在公开仓库之外。

VoDog 删除通话会协调受支持的服务端记录与归档，但不自动抹除每份已下载 MP3、独立 BCR 录音、本机 macOS 录音、日志或备份。核对实际删除与保留内容、保留任务运行时机。内容清理不能删除命令账本或身份栅栏。

开启录音或外部 AI 处理前，为自己的使用场景安排适当告知与同意，核对适用要求和供应商政策。本文不作特定法域的法律结论；应准确告知数据处理位置。

## 报告问题

公开 issue 使用最小合成复现、相关源码路径、脱敏错误码和受影响验收层。不要上传真实录音、完整日志、token、配对码、号码、SIM/模组身份或私有基础设施。敏感漏洞通过维护者指定的私密渠道报告；本文不虚构专用联系地址。
