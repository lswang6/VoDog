# 录音、归档、转录与 AI

[文档目录](README.zh-CN.md) · [English](recording-ai.md)

## 三类录音

| 路径 | 内容 | 完成标准 |
| --- | --- | --- |
| 网关原始归档 | 网关侧双方原始音轨、时间元数据及支持的播放派生轨 | 身份绑定、manifest/对象校验、服务端确认 finalize |
| 媒体节点录音 | 中继桥可见的音频 | 节点完成文件且授权读取正常；不证明网关原始归档完整 |
| 独立本地录音 | 手机第三方录音器或 macOS 本机通话录音 | 存在本地文件，不代表已上传、同步或随 VoDog 记录删除 |

远程通话可同时具有网关和媒体节点录音。启用后，Pixel 本机拨出可被动采集，但不能外推到本机接听来电。macOS 本机模组直拨通过 Mac 麦克风/扬声器与 USB 音频通信，取得服务端采集绑定后才创建共享归档。绑定失败时，本机通话或独立 M4A 仍可能成功，但共享归档缺失；绑定前的音频也可能缺失。

网关归档采用冻结身份、manifest/对象完整性检查、分块续传和权威完成确认。在协议允许清理之前，不能把它当作可随意删除的上传缓存。本地目录存在、单个分块 HTTP 成功或媒体节点副本均不证明原始归档完整。保留重启恢复状态与足够空间，不能删待上传文件来隐藏故障。

播放需要授权会话及可用来源。MP3 导出需要私有缓存配置和 ffmpeg；混音导出是派生品，不能替代原始轨和时间信息。起点对齐不证明长通话没有漂移。

## 转录与报告

Control 编排通话后转录。配置 `TRANSCRIPTION_ENABLED`、供应商/模型、要求的起始边界与相应 worker。实现支持原生 Gemini 路径，或由 `TRANSCRIPTION_BASE_URL` 选择的 OpenAI 兼容端点；端点必须真正支持适配器要求的音频与模型能力。报告另有 `REPORT_AI_*` 配置。

静音或不可用音频不应生成编造文字。缺少转录可能源于无语音、功能未开、供应商故障、录音未完成或任务尚未结束。AI 实时对话文字与录音后转录是不同产物，完整度也可能不同；未核对音频时不能当作逐字证据。

## AI 代接

Control 返回可用时，SIM 可选人工（`normal`）、AI 即接（`ai`）、超时转 AI（`timeout_ai`）。供应商按账号选择。忙线策略可独立拒接冲突来电，或将另一网关的合适来电交给 AI；这不是无限并发能力。

worker 使用私有服务身份与逐通话租约：预热供应商，经 Control 提交接听，连接中继，在真实电话/媒体就绪后开放语音。供应商回复结束不等于物理电话结束；租约丢失、供应商失败或时长上限都需要明确清理与物理状态对账。

| 配置区域 | 相关设置 |
| --- | --- |
| Control 启用 | `AI_ENABLED`、`AI_WORKER_READY`、`AI_INTERNAL_TOKEN`、`AI_VOICE_PROVIDERS` |
| worker 身份 | `VOICE_CONTROL_ORIGIN`、`VOICE_INSTANCE_ID`、`AI_INTERNAL_TOKEN_FILE`、可选 `VOICE_NODE_ID` |
| 传输 | `VOICE_MEDIA_TRANSPORT`（`udp` 或 `tls`），须匹配 Control 签发的 TURN URL |
| xAI | `XAI_API_KEY`，以及受支持的 `XAI_AGENT_ID` 或 `XAI_REALTIME_MODEL` 模式 |
| 豆包 | `DOUBAO_API_KEY`、受支持音色/模型、可选 `DOUBAO_INSTRUCTIONS_FILE` |
| 限制 | `AI_MAX_CALL_SECONDS` 及供应商支持的时长/静默控制 |

示例节点名使用 `relay-primary`，实际仍需与节点注册一致。token 和人设文件私密保存，人设可能包含个人信息。不能为了方便向 worker 提供不受限用户/设备令牌或数据库访问。本指南不包含 Pixel 直连供应商的 AI 路径。

先用合成音频验证供应商，再进行获同意的真实通话。分别测试即接/超时、开场白、打断、静默结束、主叫挂断、供应商故障、录音、转录和报告。供应商测试成功不代表蜂窝或音质验收完成。音频/文字去向见[隐私](security.zh-CN.md)。
