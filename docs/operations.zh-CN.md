# 运维与验收

[文档目录](README.zh-CN.md) · [English](operations.md)

## 每次新安装的验收

逐项记录“通过、失败、未运行、受阻”及准确范围。详细证据私密保存，公开问题只使用合成示例。

| 阶段 | 需观察的结果 |
| --- | --- |
| 源码/构建 | 身份正确、依赖声明保留、可重复构建、相关测试通过、无嵌入私密配置 |
| 服务 | 数据迁移、进程健康、内部路由隔离、证书续期、存储权限和容量 |
| 认证 | 新登录、退出、会话持久/刷新、账号隔离、已启用挑战与通行密钥真实行为 |
| 网关 | 配对和 SIM 归属正确，电话/短信/媒体就绪，设置已确认，理解 OFF/ON 行为 |
| 远程电话 | 各端分别呼出、呼入、别处接听、接通前取消、双方挂断、DTMF 与双向声音 |
| 网络 | UDP/TLS 中继、客户端 Wi-Fi/蜂窝、断线重连与最终清理 |
| 短信 | 收发、支持的短号码格式、分段补全、未知结果处理、不重复执行 |
| 本机电话 | Pixel 去电观察、Mac 本机模组直拨、正确采集与同步，无路由混淆 |
| 录音 | 双方原始轨有声、时间/完整性、上传续传、授权播放/导出、缺轨或静音正确处理 |
| AI | 即接/超时、指定供应商、开场白、打断、挂断、故障清理、转录和报告范围 |
| 后台 | 配置推送环境下的物理 iOS/Android、运行中 Mac 行为、浏览器限制 |
| 韧性 | 长通话、重启、低存储、归档中断、备份恢复与删除生命周期 |

只使用明确同意的测试对象，不拨紧急号码或陌生人。合成测试不能静默切到真实号码。运营商特性在实际 SIM/网络验证，一通成功不能认证所有运营商。

## 排障顺序

1. **无法登录：**检查 origin、RP ID、TLS、系统时间、挑战配置与会话存储，不绕过认证。
2. **网关离线：**检查应用/服务、配对 epoch、网络、SIM 注册和能力诊断；心跳不代表媒体就绪。
3. **响铃无声：**检查中继候选、节点、传输匹配的 TURN 授权、防火墙/端口段、特权采集或模组 UAC、系统音频路由。
4. **结束后仍忙：**对比物理电话、服务端与待确认状态，保留命令/防重账本，用对账恢复，不能删锁或恢复旧库。
5. **短信未知：**手工重试前先核对模组结果与 ACK，不确定送达不能自动重发。
6. **无录音/转录：**区分未启用、绑定失败、无语音、上传未完成、校验器失败和供应商任务失败，不能把缺失数据重标为成功。

收集有时间范围、已脱敏的时间线，使用合成通话标签，包含事件、平台、传输与错误码。诊断可能含号码、设备信息、IP 或转录，分享前必须审核内容。

## 升级与恢复

冻结候选，变更前现场核对已安装状态。将应用、私密配置、数据库及必要录音状态备份到受限位置，验证恢复计划，在物理电话空闲时更换网关。核对兼容签名与实际功能门。

先部署兼容的 Control/schema，再部署依赖它的客户端；服务端行为只在网关合同允许时开启。目标设置与已确认设置是两件事。保留回滚制品，但不能回退数据库/防重身份去迁就旧代码。

备份必须在隔离实例验证。仅复制数据库不足以完整恢复：录音对象、网关账本、密钥、推送身份和待处理任务也可能必要。不要把同一网关 token 克隆到两个同时在线的安装。活动数据、导出、日志、缓存、备份分别制定保留规则。
