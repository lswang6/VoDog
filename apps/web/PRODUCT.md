# VoDog Web

React 19, TypeScript, Vite, and native CSS. The Web client provides SIM calling,
messages, contacts, call history, recording access, and AI conversation reports.
Normal operation requires a separately configured VoDog Control service.

The [local demo](README.md#local-fictional-demo) reuses the actual call history,
message, and report components with fictional data. Its presentation frame is
specific to the demo. It does not demonstrate real telephony or AI execution.
