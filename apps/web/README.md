# VoDog Web

React 19 + TypeScript + Vite. First-party code is AGPL-3.0-only; dependency
licenses and upstream attribution remain unchanged.

## Build and test

Use Node.js 22.18+ (or a current compatible Node version) and npm:

```sh
cd apps/web
npm ci
npm test
npm run build
```

`npm run dev` binds to loopback. Its `/api` proxy defaults to
`http://127.0.0.1:16880`; set `VODOG_CONTROL_URL` to your own Control endpoint.
The media probe allowlists in `src/media-probe.ts` and
`src/media-quality-probe.ts` contain `example.com` placeholders; configure
those together with your server before enabling real media tests. No private
service credentials or deployment configuration are included.

## Local fictional demo

```sh
cd apps/web
npm ci
npm run demo
```

Open **http://127.0.0.1:4178/demo.html**. Stop with Ctrl-C.
The demo build is written to `/tmp/vodog-web-demo`. It is separate from the
normal production build and is not included by `npm run build`.

- Navigation, call search, message selection, AI dialogue, and recording empty
  states use the real Web components with in-memory fixtures.
- Every identity, number, message, and AI exchange is fictional. Phone fixtures
  use the North American 555-01xx range. No audio recordings are bundled.
- Calling, blocking, and service writes are disabled or rejected. Single-recipient
  SMS replies append only to local page state and disappear on refresh; no SMS
  is transmitted. The message view explicitly labels this simulation.
  Summaries are written fixtures, not generated by an AI service.
- The demo never imports the authenticated app entry. It has no API proxy;
  its request adapter never delegates to native fetch. CSP blocks connection,
  frame, and media requests, and the preview denies microphone/camera access.
- The UI refuses non-loopback hosts. Use the command above locally; do not
  deploy this demo as a service. No login or live device is required.
- Report date controls show the component's current calendar window; fixture
  data stays fixed on 29 September 2026. This is a preview, not a report engine.

## Reproduce the screenshots

Start the local demo above. With `playwright-cli` installed, run from this folder:

```sh
playwright-cli -s=vodog-demo open http://127.0.0.1:4178/demo.html
playwright-cli -s=vodog-demo resize 1440 1000
playwright-cli -s=vodog-demo screenshot --filename=docs/screenshots/calls.png --full-page
playwright-cli -s=vodog-demo snapshot
```

Use the current snapshot references to click **短信**, then the **星舟工作室（虚构）**
conversation; save `docs/screenshots/messages.png`. Click **AI 与录音报告**, then
**查看录音**, and save `docs/screenshots/ai-recording-report.png`. Run `snapshot`
after navigation to refresh references. Capture the page directly, without
editing its DOM or adding external assets. Calendar text may change with the
capture date. Close only your demo session with `playwright-cli -s=vodog-demo close`.
