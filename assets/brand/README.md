# VoDog artwork

Original project artwork, licensed under the repository's AGPL-3.0-only license.
The editable master is `vodog.svg`; `vodog.png` is its opaque 1024-pixel rendering.
No external images or account data were used.

Regenerate with librsvg:

```sh
rsvg-convert -w 1024 -h 1024 assets/brand/vodog.svg -o assets/brand/vodog.png
```
