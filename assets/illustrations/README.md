# VoDog feature illustration

`vodog-feature-hero.png` is an original AI-generated feature illustration made with the built-in image generation tool, using the complete [generation prompt](hero-prompt.md). It introduces six capabilities with a fictional puppy mascot and bilingual captions. No account screenshots or operator data were supplied.

The diagram is illustrative: configured services, compatible gateways and platform permissions are required. In particular, the DJI icon does not certify compatibility with every module or firmware. See [DJI setup](../../docs/dji-setup.md).
